# English
## Project Description

**itParty** is a web application designed for participants of IT events. It allows attendees to keep track of conference and meetup schedules, register for events of interest, view schedules and live streams, and participate in interactive activities during the event. The killer features are the messenger and random coffee.
Technical Requirements
### Frontend

    React
    TypeScript
    Redux Toolkit
    React Hook Form (for form handling)
    Yup (for validation)
    Material-UI

### Backend

    Python
    Django
    PostgreSQL
    Rest API
    Nginx
    AWS Lightsail
    Celery
    Redis
    Django Channels

## Описание проекта

**itParty** - это веб-приложение, разработанное для участников IT-мероприятий. Оно предоставляет участникам возможность следить за афишей конференций и митапов, регистрироваться на интересующие ивенты, смотреть расписание и прямые трансляции, а также участвовать в интерактивах во время ивента. Киллер-фичи - мессенджер, random-кофе
